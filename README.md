# قائمة المسواك

قائمة مسواك مشتركة للعايلة. تشتغل من المتصفح بدون تطبيق وبدون حساب.

- الأغراض مرتبة حسب الأقسام: اللحوم، والخضروات والفواكه، والمفرزنات والثلاجة، والأشياء الثانية، وآخر شي المنظفات والزقاير.
- تدوس على الغرض يصير عليه صح أخضر، وتزيد أغراض جديدة من الشريط اللي جوه.
- كل اللي عندهم الرابط يشوفون نفس القائمة، وتتحدث كل كم ثانية.
- كل ما أحد يزيد غرض، يوصل إشعار عن طريق تطبيق ntfy.

## التشغيل

1. سوّ مشروع على [Firebase](https://console.firebase.google.com) وفعّل فيه **Realtime Database**.
2. خلّ قواعد الصلاحيات (Rules) كذا:
   ```json
   { "rules": { "masswak": { ".read": true, ".write": true } } }
   ```
3. انسخ رابط قاعدة البيانات وحطه في `DB_URL` داخل `index.html`.
4. فعّل GitHub Pages للمستودع، وأول ما تنفتح الصفحة تنحط فيها الأغراض الأساسية من نفسها.

## كيف تنحفظ البيانات

- القائمة محفوظة على Firebase Realtime Database، والإشعارات تمر عن طريق [ntfy.sh](https://ntfy.sh).
- أي أحد عنده رابط الصفحة يقدر يعدّل على القائمة، فلا تنشره برا العايلة.
