# قائمة المسواك

قائمة مسواك مشتركة للعائلة. تشتغل من المتصفح بدون تطبيق وبدون حساب.

- الأغراض مرتبة حسب الأقسام: اللحوم، والخضروات والفواكه، والمفرزنات والثلاجة، والأشياء الثانية، وبالأخير المنظفات والزقاير.
- تدوس على الغرض يصير عليه صح أخضر، وتزيد أغراض جديدة من الشريط اللي جوه.
- كل اللي عندهم الرابط يشوفون نفس القائمة، وتتحدث كل كم ثانية.
- كل ما أحد يزيد غرض، يوصل إشعار عن طريق تطبيق ntfy.

## التشغيل

1. فعّل GitHub Pages للمستودع: Settings ← Pages ← اختار الفرع، والمجلد `/ (root)`.
2. افتح رابط الصفحة ودوس **"سوّي القائمة"**. هذا يسوي القائمة ويحطلها رقم بآخر الرابط (`#l=...`).
3. من **الإعدادات** انسخ رابط القائمة ودزه للأهل.
4. للإشعارات: نزّل تطبيق **ntfy**، دوس +، والصق اسم القناة اللي يطلع بالإعدادات.
5. على الآيفون: افتح الرابط بـ Safari، دوس زر المشاركة، واختار "إضافة إلى الشاشة الرئيسية".

## كيف تنحفظ البيانات

- القائمة محفوظة على [jsonblob.com](https://jsonblob.com)، والإشعارات تمر عن طريق [ntfy.sh](https://ntfy.sh). الخدمتين مجانيات وما يحتاجن حساب.
- أي واحد عنده رابط القائمة يگدر يعدل عليها، فلا تنشره برا العائلة.
- jsonblob يمكن يمسح القائمة إذا ظلت فترة طويلة محد يفتحها.
